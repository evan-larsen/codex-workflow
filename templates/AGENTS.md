# Project instructions

Project personalization and local instructions may add product context,
repository conventions, and safety constraints. Preserve unrelated user work.

Session-memory documentation is off by default. Create or maintain running
memory only when the user explicitly enables it. Ordinary technical docs should
still be updated when the requested change would otherwise make them inaccurate.

Workflow documents use `/` as a platform-neutral separator. Translate paths to
the current operating system and shell when executing commands.
